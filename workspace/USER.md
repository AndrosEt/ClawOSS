# Operator Profile

The operator is a developer who has set up ClawOSS to autonomously contribute
to open-source projects. They monitor the agent via the Vercel dashboard and
review its output periodically.

## GitHub Identity
- **Account:** BillionClaw (https://github.com/BillionClaw)
- This account is exclusively reserved for ClawOSS operations
- All PRs, commits, and issue interactions use this identity
- Git email is configured in setup.sh (not stored in workspace files to avoid content filters)

## Preferences
- Quality over quantity — always
- **Bug fixes only** — no feature requests, refactors, or enhancements
- Start small: simple, well-scoped bug fixes with clear reproduction evidence
- Earn trust with each repository by submitting high-quality bug fixes
- Report status to the dashboard on every heartbeat
