# Collaboration Space

All teammates MUST write findings, research, and coordination notes here as markdown files.
Each teammate owns their own file(s). Read each other's files frequently.

## File naming
- `{teammate-name}-{topic}.md` (e.g. `researcher-repo-profiles.md`, `problem-finder-audit.md`)
- Update your files as you work — don't just write once

## Rules
- Write here, not just in DMs — DMs are ephemeral, files persist
- Read other teammates' files before starting related work
- Keep files concise and actionable
